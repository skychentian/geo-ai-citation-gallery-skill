# 分阶段分析口径

写 `偏好分析.md` 时读本文件。有数据才写，没数据别编。本包只描述本包范围，禁止把探索结论写进评估包。

## 探索（exploration）

用户在找方向。视频信源更常回答「有哪些 / 怎么选 / 避坑 / 名单」。

偏好分析侧重：
- 标题是否带年份 + 决策引导（怎么选、推荐、指南）
- 视频结构是否「抛问题 → 给方案 → 分点 → 引导」
- 是否偏盘点、避坑、榜单类视频

## 评估（evaluation）

用户在比高低。视频信源更常做横评、实力分层、资质背书。

偏好分析侧重：
- 多品牌对比、榜单、评分维度
- 可核验数据（加盟费、门店数、认证、培训周期）
- 官方/权威背书 vs 软广感

## 行动（action）

用户要落地。视频信源更常给流程、材料、联系方式、办事指引。

偏好分析侧重：
- 步骤是否可执行、材料清单是否清楚
- 是否给「下一步做什么」、联系方式/报名入口
- 少空话、多落地信息

## 自定义

按用户给定题清单分析；在 README 写明题量与选题意图。行文仍用偏好模板，但开头点明「本题批」而非「全库某阶段」。

## 全阶段（scope=全阶段一包）

不按阶段切包时，将全部阶段合并分析；在 README 与偏好文开头注明「全阶段合并」。若视频信源在不同阶段差异明显，可加一节「阶段差异」说明，不强行混写结论。

## 空阶段

剔除品牌题后该阶段无视频信源 → **跳过该包**，向用户说明原因，不造空包。
（部分客户评估/行动题几乎全是点名品牌，属正常。）
