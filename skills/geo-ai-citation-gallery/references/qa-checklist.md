# 验收标准（Acceptance）

**原则：任一 P0 不通过 → 验收不通过，不得对客户交付 / 不得标完成。**  
P1 可带缺口说明限期补；P2 为体验建议，不挡验收。

判定人：执行 AI 自检后，产品侧（GEO 产品）抽查；客户可见交付以产品签字为准。

---

## 怎么判

| 结果 | 条件 |
|------|------|
| **通过** | 全部 P0 = Pass；P1 若 Fail 须在页内或交付说明写明缺口与补抓计划 |
| **不通过** | 任一 P0 = Fail |
| **退回重做** | 编造数据、用词错误、标签 >5、口播冒充、截屏当成品等诚信/硬规则类 Fail |

抽查最低量：随机抽 ≥5 条详情卡 + 全文搜「应用」+ 跑标签脚本。

```bash
# 标签门禁（对 data.json 或等价文件）
python scripts/normalize_hashtags.py gallery/data.json   # 截断后全 ≤5
# 用词门禁
rg -n '应用次数|应用率|次应用' gallery/index.html && echo FAIL || echo PASS
```

## P0 — 不达标即不通过

| ID | 验收项 | Pass 标准 | 怎么验 | Fail 即 |
|----|--------|-----------|--------|---------|
| A1 | 指标用词 | 页面可见文案（Hero、指标说明、Tab、图表轴/图注、详情）一律「引用次数 / 引用率 / 条均引用」等；**零**「应用次数 / 应用率 / 次应用」 | `rg` 全文 + 人眼扫 Hero/指标条 | 退回改文案 |
| A2 | 标签上限 | 每条样本展示与分析用 `hashtags.length ≤ 5`；若曾超额须已截断；分析不得声称未截断的「12 个标签」 | 脚本/JSON 断言 + 详情卡抽查 | 退回截断重灌 |
| A3 | 数字口径 | 真实 `0` 显示 `0`；未抓到显示「暂未抓取到」或等价；**禁止**把抓取失败写成 `0` | 抽查互动为 null 的卡；对照 progress/缺口表 | 退回改数据 |
| A4 | 文字三字段 | 短标题 ≠ 发布文案 ≠ 口播文案；缺口播标缺口；**禁止**用发布文案填 `transcript` | 抽 ≥5 条：有 transcript 的与 caption 比对 | 退回清字段 |
| A5 | 画面来源 | 成品图来自媒体 URL 下载/抽帧；无帧处标「暂未抓取到」；**禁止**整页截屏冒充作品画面、禁止假图 | 对照 `capture_progress` / `shots/`；无 progress 却「齐全」→ Fail | 退回重抓或标缺口 |
| A6 | 五 Tab 结构 | 且仅这五且顺序固定：①高引用特征总结 ②内容分类 ③标题·正文·标签 ④互动与时长特征 ⑤详情 | 打开页面点一遍 | 退回改模板结构 |
| A7 | 引用率分母 | 引用率 = 引用次数 ÷ 本批总回答数（来自 manifest/`total_answers`）；禁止自造分母 | 对照诊断包 meta | 退回重算 |
| A8 | 安全 | 页面与交付仓库无 API key / cookie / 账号密码 / 内网地址泄露 | 搜 key/token/password；源码扫描 | 退回清除后重发 |
| A9 | 视觉与类目 | 客户交付为晨光陶瓷视觉；**不**套学习工作台「纸感」皮 | 对照品牌 tokens / 规范 | 退回换皮 |
| A10 | 清单可追溯 | TopN 每条有可点原链或等价 `url`；rank 与引用次数可回溯到诊断包聚合 | 抽查 URL + 与清单 CSV 对一下 | 退回补链/重聚合 |

## P1 — 应达标；Fail 须书面缺口，否则不建议对客

| ID | 验收项 | Pass 标准 | 怎么验 |
|----|--------|-----------|--------|
| B1 | 分类 | 互斥主类约 4 类；每条只进一类；含图文 vs 口播总体占比 | 分类 Tab + `main_category` |
| B2 | 案例与规律 | 每类 ≥1 个真实案例 + 一句「拍的时候怎么排」白话规律 | 分类/特征 Tab |
| B3 | 详情卡字段 | 有：短标题、发布文案（可展开）、标签≤5、账号、粉/赞/藏/转（或缺口文案）、画面区、原链；口播有秒、图文有页数（或缺口） | 抽卡 |
| B4 | 指标说明 | 引用次数/引用率说明可折叠或等价可读解释 | UI |
| B5 | 图表诚实 | 散点/分桶若剔可疑全 0，须脚注剔除条数；相关≠因果，不作因果主结论 | 互动 Tab 文案 |
| B6 | 监测品牌 | 品牌仅旁注；页面主叙事非「唯品牌种草榜」 | 人眼 |
| B7 | 抓取进度 | 有 `capture_progress`（或等价表）与画面缺口一致 | 文件存在且与页一致 |

## P2 — 体验建议（不挡验收）

| ID | 项 | 说明 |
|----|----|------|

## 验收记录模板（交付时可贴）

```text
项目/客户：
样本 N / 总回答数：
页面 URL 或路径：
P0：A1__ A2__ A3__ A4__ A5__ A6__ A7__ A8__ A9__ A10__  （Pass/Fail）
P1 缺口：
结论：通过 / 不通过
验收人/日期：
```

**一票否决（直接不通过）**：编造引用次数或互动；假画面；口播冒充；「应用率」未改干净；任意条标签展示 >5；泄露密钥。
