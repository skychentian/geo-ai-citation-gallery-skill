# 视频偏好分析模板（爆款分析 · Markdown 归档）

> **本文件只约束 `偏好分析.md`（可选内部归档）的正文结构。**
> **客户主交付 HTML 必须套同技能 `assets/template.html`（晨光陶瓷五 Tab 画廊）**，把本模板的洞察填进画廊 Tab / `STATS`，禁止另起绿头 KPI 壳（见 `assets/legacy/`）。

基于拉取到的 Top N 条高引用视频文案，分析「AI 到底偏好引用什么样的视频内容」。
以数据包期为单位、条数可配置。所有 `<尖括号>` 占位符按当前客户的真实清洗结果填充，
**不要沿用其他客户、其他行业的词**。

> 数据源：<数据包日期> 期监测 · 分析范围 **<探索|评估|行动|自定义|全阶段>** · 非品牌高引用视频 Top<N>，共 <N> 条（文章另计，未纳入）。
> 清洗口径：逐维度说明哪些样本有标题、发布文案、口播、画面或互动证据；短文案、无口播不统一排除。
> 引用次数为 <平台清单> 各平台合计（全部视频平台模式则分开注明）。
> **本包只描述该范围下的偏好**；若另有探索/评估包，结论不要混写。
> 样本口径：按当前维度 eligibility 使用可核验证据；播放量/点赞等数据未获取到则不写，不编。

---

## 一、样本与可信度

- 可分析 / Top 清单 / 排除原因摘要（如：拉取失败 2、纯 BGM 无口播 1、过短 1）
- 数据可得性：多少条拿到了时长/播放量/账号信息，多少条只有标题+文案
- 一句结论：本包结论主要建立在哪类视频上

## 二、标题与话题标签特征（归纳 3～5 类）

对可分析样本的标题与 `#话题标签` 做归类，不要只列词频。**标签完整规范化后分析，不截断原始证据。**

| 类型 | 典型公式 | 条数 | 代表视频 |
|---|---|---|---|
| 如：行业痛点+解决方案 | `…怎么解决…` | <n> | 《…》《…》 |
| 如：品牌+加盟/招商 |  |  |  |
| 如：多品牌横评盘点 |  |  |  |
| 如：知识科普/干货 |  |  |  |
| 如：活动/报名/资讯 |  |  |  |

**话题标签观察**：高频标签是什么；AI 是否依赖标签理解视频主题。

**标题侧结论**：本包最吃哪一类标题；和文章版（若有）差在哪。

## 三、口播/视频结构类型（归纳 3～5 类）

| 结构类型 | 骨架 | 条数 | 代表视频 | 为何易被引 |
|---|---|---|---|---|
| 如：痛点→方案→背书 | 开头抛问题→给方案→讲优势→引导咨询 |  |  |  |

| 如：干货科普 | 定义→分点→举例→总结 |  |  |  |
| 如：案例展示 | 实拍/门店/学员→数据→转化引导 |  |  |  |

**结构侧结论**：AI 偏好的视频底层骨架一句话。

## 四、文案风格与信息密度

用条目写清，每条带例子：

- **口播语气**：招商口吻 / 教学口吻 / 测评口吻 / 资讯播报…
- **信息密度**：是否必有可核验数据
- **转化引导**：结尾是否引导「私信/评论区/留资/到店」
- **信任锚点**：品牌背书 / 实地实拍 / 资质认证 / 学员案例 / 政策引用
- **配字幕 vs 纯口播**：文案是否自带字幕信息、是否依赖画面

## 六、账号与数据特征（可得才写）

- **账号类型分布**
- **时长**：集中在哪个区间

## 七、给品牌的可复制视频写法（5～7 条）

要具体到「标题怎么写、开头 3 秒放什么、中段讲什么、结尾怎么引导」，避免空话。
