# GEO AI 高引用视频画廊

把「AI 爱引什么样的短视频」做成可交付的客户证据页：说人话、可执行、可复用。目标是指导内容生产；监测品牌只作旁注，禁止全文品牌导向。

参考模板：同目录 [`assets/template.html`](assets/template.html)。字段说明：[`assets/feature-stats.schema.md`](assets/feature-stats.schema.md)。

## 何时用

- 已有高引用短视频样本清单（含应用次数 / 应用率）
- 需要客户可读的晨光陶瓷风格画廊（指标 + 分类 + 图表 + 详情卡 + 拍摄指引）
- 任意行业赛道均可；用 `{{SECTOR}}` / 样本说明占位，勿写死单一客户叙事

## 硬规矩（定稿规范）

### 1. 目标

- 分析 AI 抓取 / 高引用偏好 → 指导内容生产
- 监测品牌只旁注（例如「标题含监测品牌」筛选），禁止全文品牌导向、禁止做成种草汇报

### 2. 说人话

- 客户页白话；禁止 AI 腔（「赋能」「闭环」「深度洞察」堆砌）
- 结构：前短后详——Hero / 结论先短句，细节进折叠、图表下方、详情卡

### 3. 指标口径

- 正文用专业术语：应用次数、应用率、条均引用、分桶、图文 / 口播等
- Hero 下提供可折叠「指标说明」，用人话解释口径
- 拍摄指引仍白话（「拍的时候怎么排」），与指标术语分区

### 4. 数字显示

- `0` 显示 `0`
- 未抓到显示「暂未抓取到」
- 禁止用 `—` / `-` 混淆「零」与「缺失」

### 5. 五个 Tab（顺序固定）

1. 高引用特征总结
2. 内容分类
3. 标题 · 正文 · 标签
4. 互动与时长特征
5. 详情

### 6. 内容分类

- 互斥主类：按赛道归纳，通常约 4 类；每条只进一类
- 同时展示图文 vs 口播占比（总体 + 按类）
- 每类：1 个典型案例 + 可执行脚本规律（拍的时候怎么排）

### 7. 图表

- 每图下方一句人话结论（takeaway）
- 图题可用专业名 + 可选问题副标题
- 不要把 Spearman 等相关统计当主结论；相关性最多作脚注

### 8. 详情卡

- 大标题；标题 ≠ 文案
- 文案三行预览，可展开
- 字段标明「文案 / 标签」
- 展示粉丝 + 赞 / 藏 / 转
- 画面缩略图 + 原链
- 默认不展示样例监测问题
- video id 弱化（小字、低对比）

### 9. 时长

- 口播用秒（可再分桶）
- 图文用页数 / 帧数（不是秒）
- 缺数据标缺口，勿 silently 跳过

### 10. UI（GEO Lens · 晨光陶瓷）

- 使用晨光陶瓷 tokens（porcelain / tray / plate / blue）
- `.card .num` 只用于大数字卡；表格数字须显式字号（如 `.ctype-table td.num { font-size: var(--cz-fs-13); ... }`），防止被 `.card .num` 撑到 27px

### 11. 流程

```text
样本清单 → 元数据 → 画面 + 互动 → 分析灌数
→ 套 assets/template.html
→ 校验（数字口径 / Tab / 字号 / 品牌旁注）
→ 发布（可 here.now，保留 slug）
```

### 12. 画面与媒体抓取（重要：其他 AI 必读）

抖音 / 短视频「画面 + 互动」与引用清单是**两步事**。任何能读本 skill 的 AI 都可能参与出页；**抓取**另需浏览器 / 桌面或固定脚本，成功率不保证。更细步骤见 [`assets/capture-pipeline.md`](assets/capture-pipeline.md)。

#### 分工

| 产物 | 来源 | 是否需要登录抖音 |
|------|------|------------------|
| 引用清单 / 应用次数 | GEO 诊断包（xlsx/csv 信源 URL） | **不需要** |
| 画面帧 / 部分元数据 | 公开分享页 DOM / 网络媒体 URL + 本机下载抽帧 | 多数公开页可未登录；遇登录墙/验证码则停 |

- 不要假设「没登录就绝对抓不到」。
- 也不要假设「一定稳」。
- **出页**：读 skill 即可套 `assets/template.html`。
- **抓取**：需要浏览器 / Computer Use / 固定脚本；失败就标缺口，禁止编造。

#### 已验证可行的做法（免账号登录）

1. 从诊断包筛 TopN（按应用次数 / 应用率）。
2. 用浏览器打开抖音**公开分享页**（多数可未登录打开；遇登录墙 / 验证码则停，标缺口或转人工）。
3. 从页面 DOM / 网络里捞出**图床或视频媒体 URL**（不是去创作者后台）。
4. 本机小服务接收 `rank` + meta + media URL：图文直接下载图片；口播下载视频后用 ffmpeg 抽帧（如前几帧），可回退 poster / 封面。
5. 下载请求带常见 `User-Agent` + `Referer: https://www.douyin.com/`。
6. 进度写入 `capture_progress`；失败写明原因（403、无 video URL、仅封面等）。页面用「暂未抓取到」/ 缺口，**禁止编造帧图或互动数**。

目录约定示例：`shots/01_1.png`、`shots/01_2.png`（`NN` 为排名两位、`k` 为帧序号）。

#### 已知失败模式

- CDN **403**（部分图床 URL 拒下）
- 页面 JS **不暴露**可下载视频地址
- 只抓到**部分帧** / 仅封面 poster
- 互动数空或假 `0`（需重试，或排除出散点图并注明）

#### 推荐给其他 AI

- **优先**：人 / 专用脚本先出齐 `shots/` + metadata / engagement JSON，再套模板。
- **若自行抓**：按上面链路；有 Computer Use / 浏览器代理更好。
- **纯无浏览器的编码模型**：不要硬编截图或假互动数。
- 可参考本仓库 [`assets/capture-pipeline.md`](assets/capture-pipeline.md)。

### 13. 参考模板

- 复制 `assets/template.html` 为交付 `index.html`
- 替换内嵌 `STATS` / `data`（或改为加载 `data.json`）
- 占位符：`{{SECTOR}}` / `{{MONITOR_DATE}}` / `{{PLATFORM}}` / 样本说明
- Demo 数据仅示意结构，交付前换成当前赛道样本，勿绑定真实客户品牌叙事为默认文案

## 校验清单（发布前）

- [ ] 五 Tab 齐全且顺序正确
- [ ] 指标说明可折叠；0 / 暂未抓取到 未混用
- [ ] 分类互斥 ≈4 类；含图文 vs 口播；每类 1 案例 + 脚本规律
- [ ] 每图有一句人话结论；Spearman 非主结论
- [ ] 详情卡：大标题、文案可展开、字段标签、粉丝+赞藏转、画面、原链；监测问题默认隐藏；video id 弱化
- [ ] 口播秒 / 图文页；缺口已标注
- [ ] `.ctype-table td.num` 等表格字号未被 `.card .num` 污染
- [ ] 监测品牌仅旁注；全文非品牌导向
- [ ] 无 API key / credentials 进仓库或页面
